# Ideal Customer Profile

We sell AI agents for intake, quoting, scheduling and document processing.
Best fits: firms that answer phones/emails manually and quote by hand.

## Pain Points
- Manual phone/email intake
- Hand-written quotes and proposals
- Paper-based scheduling
- Manual document processing
- Follow-up falls through cracks

## Anti-patterns (DO NOT target)
- Web/digital agencies (they are competitors/channel partners)
- Software consultancies
- Media/design studios
- Companies with >50 employees (too complex for v1)
